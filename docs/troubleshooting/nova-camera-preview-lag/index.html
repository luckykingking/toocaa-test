NOVA Camera Preview Is Slow or Frozen

Distinguish a stale camera image from a connection failure or an overloaded Studio preview, then check the smallest reproducible case.

Applies to: TOOCAA NOVA

Compare the live view and the design preview

A camera frame that does not refresh is different from a design preview that takes too long to generate. Note whether Studio remains connected, the device screen responds and the software can refresh an empty-work-area image. Do not move the blank and start engraving against an old overlay.

Reduce the application load

The NOVA FAQ discusses limited system-drive space affecting camera-image loading and complex multi-design previews exhausting browser resources.

  1. Save the design before closing tabs or restarting the browser.
  2. Close unnecessary tabs and applications and check available system-drive space.
  3. Test a simple project with one visible design layer.
  4. Hide other complex layers and refresh the overlay before positioning.

Check the connection without changing several things at once

For USB, check the data cable, selected port and competing control sessions. For Wi-Fi, confirm the current address, shared subnet and device confirmation. Compare a supported alternate connection only after saving the project and following the normal reconnect procedure. Do not assume a frozen picture is proof of a defective camera.

Keep blur and latency separate

A refreshed image with fixed spots or blur may need the official top-cover camera cleaning procedure, followed by calibration. Cleaning a lens will not resolve an overloaded preview computation. If lag persists with a simple project, report browser/OS versions, connection method, available disk space and whether the camera image or design preview is affected.

Frequently asked questions

Can I engrave using the last camera picture if refresh fails?

Do not rely on a stale overlay after the workpiece or machine state changes. Restore a current preview and verify placement before processing.
