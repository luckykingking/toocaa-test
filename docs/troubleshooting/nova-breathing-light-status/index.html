NOVA Status Light Shows an Unexpected Pattern

Record the light pattern together with the touchscreen message and operating stage rather than applying another machine's color codes.

Applies to: TOOCAA NOVA

Use the screen and the light together

A light is a status cue, not a complete diagnosis. Record its color, whether it is steady, breathing or flashing, and the exact touchscreen message. Note whether NOVA is starting, framing, focusing, processing, paused or updating. That context is more useful than reporting only that the light is red.

Do not use an L2 light chart for NOVA

The L2 indicator-light document describes L2 states. It does not establish NOVA meanings, and an informal green-ready / red-error chart should not be substituted for a model-specific reference. Use the current NOVA information and the actual on-screen warning before choosing a remedy.

Respond to the underlying condition

Start with the condition shown by the device.

  1. For a cover or module warning, stop and check normal installation without defeating a safeguard.
  2. For a focus or camera message, keep the exact wording and use the relevant NOVA guide.
  3. For an update notice, let the documented update process complete before a normal restart.
  4. For smoke, overheating or unexpected movement, stop processing and address the hazard first.

Send a useful status record

If the pattern remains unexplained, provide support with a short recording taken without recreating a hazardous job, the screen message, installed module and firmware version. Do not try to force a preferred color by disabling sensors, changing hidden settings or repeatedly starting a failed job.

Frequently asked questions

Can I use the L2 beep and light table to diagnose NOVA?

No. A reference for L2 is not a NOVA status decoder. Keep the NOVA screen message and the operating stage together with the observed light pattern.
