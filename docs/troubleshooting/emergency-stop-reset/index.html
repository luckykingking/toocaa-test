After an Emergency Stop: Before You Restart

Make the work area safe, identify why the job stopped and recheck placement before starting a new job after an urgent stop.

Applies to: TOOCAA L2 / TOOCAA NOVA

Resolve the reason for stopping

An emergency stop is a response to a condition, not a nuisance to clear. Keep the machine stopped while smoke, heat, unexpected movement, damaged parts or an unsafe workpiece remain. Follow the exact machine controls and safety instructions; different models do not necessarily have the same button or reset mechanism.

Inspect with the right power state

For access or maintenance, disconnect power and let parts cool as directed by the manual.

  1. Remove the cause of an obstruction only when the machine is stopped.
  2. Inspect the stock and fixtures for movement, heat damage or a partially cut section.
  3. Check that all protective parts are correctly installed.
  4. Record any alarm, error screen and the stage where processing stopped.

Distinguish Pause from Stop

NOVA's Offline Mode guide distinguishes pausing/resuming from Stop: Stop ends that job and returns to the home screen. Do not assume that releasing a control or reconnecting Studio restores the original coordinate state or resumes at the correct point. Use the model's documented continuation behavior.

Prepare a new controlled start

Confirm machine identity, origin, workpiece placement, focus and all job settings before another framed start. A partially processed piece can react differently to a repeated full job. If there was a collision, lost position, persistent heat or a recurring warning, request support instead of restarting on the same customer part. Never use an undocumented button sequence to override an unresolved stop condition.

Frequently asked questions

Does Stop behave exactly like Pause?

No. NOVA's offline guide says Stop ends the current job. Check the documented behavior for the actual model before expecting processing to continue.
