TOOCAA Studio Freezes or Crashes During Preview

Recover a browser-based Studio workflow, isolate complex artwork and preserve your project before clearing data or retrying a batch.

Applies to: TOOCAA NOVA / TOOCAA L2

Save the project before troubleshooting

Record whether Studio freezes during import, preview generation, connection, transfer or processing. If the browser responds, save a project copy and note the software/browser version. A frozen preview is not permission to assume a connected laser has stopped; use the machine's documented controls if a job is active.

Reduce browser and artwork load

The NOVA FAQ describes preview freezes when several complex designs are placed on a single layer. Test a smaller working set instead of restarting the same overloaded job repeatedly.

  1. Close unnecessary tabs and nonessential applications.
  2. Open a copy containing one simple object and generate its preview.
  3. Move separate designs to different colored layers using Studio's Move to command.
  4. Hide unused layers with their visibility control and verify one design at a time.

Check disk space and the connection separately

The same FAQ identifies insufficient system-drive space as a cause of camera-image and firmware-update failures. Check available space without deleting project files or browser data blindly. A successful preview with a failed transfer belongs to connection troubleshooting; a preview that fails while disconnected points toward the file or application environment.

Build a reproducible support example

Keep the smallest project that reproduces the freeze and describe the stage at which it occurs. Include layer count, image dimensions, browser, OS and available memory if known. Do not repeatedly send a partially prepared job, erase all saved site data before backing up, or install an unofficial Studio build to work around the symptom.

Frequently asked questions

Why does a simple file work while a batch freezes?

A complex batch can require substantially more preview resources. Isolate designs and hide unused layers to identify whether the failure follows a particular object or the size of the combined job.
