X/Y Position Drift Between Engraving Passes

Track whether a shifted engraving comes from moving stock, changed coordinates, or a machine that is losing its position.

Applies to: TOOCAA L2 / TOOCAA NOVA

Keep the first and last positions

A design that shifts a little more with each pass is different from a constant camera-overlay offset. Mark the blank's orientation and retain the file. Do not move the material or drag the artwork to compensate before recording the original displacement.

Check the reference that moved

Examine each reference independently.

  1. Check whether the blank or fixture moved on the working panel.
  2. Confirm that the file was not reimported at a different size or position.
  3. Check origin and coordinate mode in the selected machine profile.
  4. Check whether the problem started after a collision, accessory change or interrupted movement.

Separate camera alignment from machine travel

On NOVA, an overlay that stays consistently offset calls for the official camera-calibration workflow. A toolpath that moves farther off with successive passes may involve stock movement or lost machine position. Recalibrating a camera cannot repair a slipping blank, an obstructed axis or a displaced origin.

Use a small baseline, not repeated full jobs

When the machine is safe, compare a simple outline and a short filled sample on securely held offcut material. Stop if position is lost again. Send support the displacement direction, the file, machine profile and whether vectors and images are both affected. Do not flash firmware or edit motion calibration values merely to make a displaced sample line up.

Frequently asked questions

Can I fix a drifting job by moving the next layer?

That can hide the symptom while the references continue to move. Establish a stable workpiece, machine origin and toolpath before restarting the job.
