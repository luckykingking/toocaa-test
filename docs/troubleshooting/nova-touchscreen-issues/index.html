NOVA Touchscreen Unresponsive or Frozen

Identify a frozen interface, keep an active job safe and follow the documented restart, reset and firmware checks.

Applies to: TOOCAA NOVA

Determine whether only the screen is affected

Note whether the screen is blank, frozen on one page, displaying an update, or responsive but ignoring a particular control. If processing is active, do not assume that a frozen picture means the laser has stopped. Use the documented machine stop procedure when it is necessary to make the work area safe.

Preserve information before changing settings

Record the displayed page, firmware version if available, the last action and whether Studio is still connected. Keep a photo of an error screen instead of repeatedly tapping controls. An update-in-progress screen belongs to firmware recovery, not ordinary touchscreen troubleshooting.

Use the FAQ recovery when the settings menu responds

For a malfunctioning or unresponsive display, the NOVA FAQ describes Restore Factory Settings followed by a restart and checking the firmware release. Use that menu route only when the machine is idle and the relevant controls can actually be reached. Record network and job settings first, let the restart fully finish, then reconnect and verify the configuration.

When the controls cannot be reached

Do not invent a button-hold combination or attempt a firmware reflash through an unrelated device utility. A completely inaccessible screen, a repeating boot failure or visible physical damage should be reported to support with the exact startup sequence. After recovery, check a simple idle interaction and the normal connection before sending another processing job.

Frequently asked questions

Can I use Restore Factory Settings while an update is running?

No. Use the firmware-update guidance for an update in progress. A general screen reset is not a documented way to interrupt firmware writing.
