NOVA 90-Degree Rotary Setup & Alignment

Set up the NOVA rotary with the machine powered off, then check accessory detection, workpiece diameter and framing.

Applies to: TOOCAA NOVA

Use the NOVA rotary instructions

The NOVA rotary uses the machine's rotating X-axis arrangement. It is not the L2 5-in-1 rotary installation. Check the rotary identity, supported workpiece dimensions and installed laser module before starting. Workpiece length limits differ between the infrared and diode modules, so use the table in the linked NOVA rotary manual.

Prepare the machine with power disconnected

Use the illustrated guide alongside the machine so the named panels and connection points can be identified correctly.

  1. Stop, switch off, disconnect power and let the module cool.
  2. Remove the blade cutting panel and aluminum protective plate using the orange handle, as illustrated.
  3. Loosen the X-axis knob as directed, rotate the axis 90 degrees and secure the knob.
  4. Install the rotary at the documented right-side connection point, secure it and connect the X-A cable to the expansion port.
  5. Clear tools and obstructions and close the lid before reconnecting power.

Check detection and the processing diameter

Connect NOVA in TOOCAA Studio and confirm that the accessory is detected. Enter the workpiece diameter at the area that will actually be engraved, not the widest part of a tapered cup. Check grip, balance and clearance over the full planned rotation before applying the design.

Frame and focus before processing

The NOVA rotary guide distinguishes hard objects, which can use autofocus, from soft objects that need the documented manual height adjustment. Frame the design and make sure the processing area remains on the object, not the machine. If rotation is absent or irregular, stop and check the documented axis connections and diameter setting; do not substitute L2 rotation values.

Frequently asked questions

Can I follow the L2 rotary setup for NOVA?

No. NOVA uses a different accessory and a 90-degree X-axis setup. Follow the NOVA rotary manual and its module-specific size limits.
