LightBurn Does Not Detect the L2

Review the L2 device setup, data connection, selected port, and other software using the machine.

Identify the symptom

Treat the device profile and the connection as separate checks. A profile can exist even if the machine is disconnected, while a detected port does not prove the selected profile or origin is correct.

Checks in order

Begin with the visible status, configuration, and material. Keep a note of each check and its result. Inspect hardware only with the machine stopped and power disconnected as directed by the manual.

  • Follow TOOCAA's current L2 LightBurn setup instructions.
  • Check normal machine readiness and a known USB data cable.
  • Close competing machine-control software.
  • Verify the documented device type and selected port.
  • Record the software error and operating-system device behavior for support.

Stop and seek support when needed

Do not copy a different model's firmware or controller configuration to force detection. Confirm work area and origin before a test after the connection is restored.

What to include in a support request

Send the exact model and module, software version, material identity, file details, job settings with units, and the full error message. Describe the last successful job and any recent change. Include clear photos when safe; do not reproduce a hazardous event to record it.
