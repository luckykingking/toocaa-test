NOVA Exhaust Airflow Is Weak or the Fan Stops

Inspect the NOVA exhaust route and built-in filter, distinguish an optional purifier problem, and stop for unsafe smoke conditions.

Applies to: TOOCAA NOVA

Stop for smoke escaping into the room

Do not continue a job with smoke leaking from the enclosure, a persistent unusual odor, a stopped fan or an active safety warning. A dual-channel design still needs a clear and correctly assembled exhaust route. Let the machine stop and cool before inspecting it.

Inspect the complete route

Check the path in order rather than looking only at the visible fan.

  1. With power disconnected, inspect accessible exhaust openings and tubing for blockage or a sharp bend.
  2. Check the rear built-in filter housing for accumulated residue and correct seating.
  3. If an optional purifier is fitted, inspect its own filter and airflow according to that accessory's instructions.
  4. Keep the machine's laser-module cooling fan separate from these exhaust checks.

Clean only the component that is meant to be cleaned

The NOVA built-in filter guide permits rinsing the removed built-in filter separately with clean water and requires complete drying before reinstallation. That permission does not extend to electrical parts, the machine interior, or every purifier cartridge. Do not wash an optional purifier filter unless its own instructions explicitly allow it.

Verify before returning to processing

After correct reassembly, remove all tools and wipes, close the cover and check normal homing and exhaust operation using the manual. If airflow is still poor or a fan sounds abnormal, stop again and contact support. Include whether a purifier is fitted, which filter was serviced and whether the problem existed before maintenance.

Frequently asked questions

Can I rinse every filter in the exhaust system?

No. NOVA's removed built-in machine filter has a documented rinsing procedure. An optional purifier cartridge has separate maintenance instructions and must not be treated as the same component.
