TOOCAA Studio Cannot Connect to NOVA

Check the browser connection, serial-port permission, Wi-Fi subnet and device confirmation when NOVA will not connect to Studio.

Applies to: TOOCAA NOVA

Identify the connection that failed

Record whether you selected USB or Wi-Fi and what appears in the connection dialog. A machine that has joined Wi-Fi is not necessarily connected to the current Studio session. The official NOVA tutorial recommends Google Chrome and asks you to select NOVA explicitly before choosing the connection method.

For a USB connection

Save any open design before changing the session.

  1. Connect a data-capable Type-C to Type-A cable as shown in the NOVA guide.
  2. In Studio, choose Connect Device, select NOVA and choose the USB method.
  3. Select the correct serial port in the browser permission dialog.
  4. Close another machine-control session if it is holding the connection.
  5. Keep a note of the exact permission or connection error if no usable port appears.

For a Wi-Fi connection

The computer and NOVA must be on the same network and IP subnet. The current connection guide also requires TOOCAA Connect for the browser Wi-Fi workflow; install it only through the official guide or its Chrome Web Store link. On NOVA, inspect Settings > Wi-Fi and read the current address. In Studio, use Wi-Fi Connection > Connect New Device, enter that address and confirm on the touchscreen. A guest network with client isolation can prevent communication even when both devices have internet access.

When it still cannot connect

The NOVA FAQ provides network-specific checks and a USB-assisted Wi-Fi setup. Use those before a reset. Keep firmware, browser and OS details together with the method tested. Do not open router ports, disable network security globally, or reset the machine during an active job just to make a connection dialog succeed.

Frequently asked questions

NOVA has an IP address. Why is Studio still disconnected?

Check the computer's subnet, the current device address, and the confirmation prompt on NOVA. Wi-Fi association alone does not establish a Studio connection.
