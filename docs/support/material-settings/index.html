TOOCAA Material Settings: L2 Reference & Test Records

Find published L2 settings by material, module and operation. Check thickness and speed units, and keep NOVA settings separate from L2 references.

Match all parts of a setting

Start with the exact model and installed module, then the material, actual thickness and operation. A cutting value is not an engraving value. The reference rows on this page are published L2 examples, not a conversion between modules and not a guarantee for every supplier or finish.

Filter the published L2 rows

The table keeps the original power, speed and passes together. All listed speeds are in millimeters per minute. An empty filter result means this reference has no matching row; it does not calculate a substitute.

Keep a useful test record

Use a suitable offcut from the same batch. Retain a photo and physical sample so later changes can be compared.

  1. Record model, module, material supplier and actual thickness.
  2. Save the artwork revision, processing mode and focus method.
  3. Record power, speed with units, passes and documented air-assist setup.
  4. Inspect separation, edge condition, small text and final dimensions.
  5. Retest after a material, module, artwork or maintenance change.

For NOVA and unlisted stock

Use the current NOVA documentation and its supported material workflow. A recognition tag or suggested preset does not prove that an unidentified material is suitable. When a matching reference is missing, send support the complete material and module details rather than interpolating the L2 table.

Frequently asked questions

Why does a filter show no result?

No row in the retained L2 source data matches that combination. Use the full current TOOCAA reference or ask support; do not infer a missing recipe.

Can these settings be used unchanged on NOVA?

No. They are L2 reference rows. Use NOVA-specific setup and material guidance.
