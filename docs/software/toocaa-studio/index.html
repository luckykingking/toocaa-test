TOOCAA Studio: Design, Connect & Prepare a Laser Job

Use browser-based TOOCAA Studio to prepare artwork, connect L2 or NOVA, check layers and preview a job before processing.

Start in the browser

Open TOOCAA Studio through the official TOOCAA software page. The current connection guides use Chrome. Keep the machine manual beside the software instructions: signing into an account, selecting a device and setting up a physical workspace are separate tasks.

Bring in the right artwork

The published Studio feature overview lists JPG, PNG, DXF and SVG imports, with SVG and GCode save options. Choose vectors for outline work and images for photographs. Check physical dimensions and text after import; the on-screen appearance alone does not prove that the final toolpath has the intended scale.

Connect the actual machine

Use the guide for the exact model, not a copied profile.

Prepare the job

Keep the first task small enough to inspect clearly.

  1. Confirm the selected device and work area.
  2. Verify dimensions, closed contours and duplicate outlines.
  3. Assign the correct operation and output state to each layer.
  4. Check power, speed units and passes against a matching reference.
  5. Refresh placement and frame the design using the model instructions.
  6. Process only with the documented safeguards, extraction and attendance.

Keep artwork and machine files distinct

Save an editable design separately from prepared machine instructions. A downloaded GCode file may contain settings for another controller or work area. Do not treat it as portable artwork. Retain the successful design, material identity, module and job settings so a later change can be diagnosed.

Frequently asked questions

Is Studio the same as a desktop application I must reinstall?

The workflow documented here is browser-based. Follow the current official connection instructions rather than an unrelated desktop or phone-app reinstall procedure.

Do layer colors print the same colors on the material?

No. Layer colors organize operations; the material and process determine the resulting appearance.
