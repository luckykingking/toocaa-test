Laser File Formats: SVG, DXF, PNG & GCode

Choose vector or image artwork, check supported TOOCAA Studio imports, and verify size, text and layers before sending a laser job.

Choose a format for the job

Use vectors for cut outlines and pixels for photographs. The formats below are listed in the current Studio feature reference; support in another application does not automatically mean Studio can import the same file.

FormatTypical useTOOCAA Studio referenceCheck after import
SVGVector outlines, logos and editable shapesImport; Save as SVGPhysical dimensions, text paths and duplicate outlines
DXFCAD-style vector geometryImportDrawing units, scale and closed contours
PNG / JPGPixel images and photo engravingImportFinished size, image detail, contrast and background
GCodePrepared machine instructionsSave as GCodeExact device and job configuration; not a substitute for editable artwork
PDF / AIMixed artwork in supported applicationsNot listed as Studio imports in this referenceUse the supported application or export suitable artwork to SVG or PNG

A picture is not a cutting outline

A PNG or JPG stores pixels. Importing it does not create a clean vector perimeter, and renaming it to SVG does not convert it. For a photo, prepare image engraving. For an outline cut, use original vector artwork or a deliberate image-tracing workflow, then inspect the resulting paths. Tiny islands and rough traced edges can matter at the finished object size.

Prepare vectors before export

Keep an editable master file and a separate machine-preparation copy. Convert text to paths when fonts may not be installed on the receiving computer. Check closed shapes, duplicate paths and the actual drawing units. A thick screen stroke can become either one centerline or outlined edges depending on export settings, so inspect the imported geometry rather than assuming it will cut once.

  • Confirm the final width and height in millimeters.
  • Check text and small details at actual output size.
  • Inspect closed contours and remove unintended duplicates.
  • Assign each operation to the correct layer after import.

Artwork, projects and machine files are different

A saved SVG is useful editable artwork; it is not proof that every machine setting has traveled with it. A GCode file is prepared for a particular controller and configuration. Do not send instructions for a different model or run a downloaded machine file whose motion, power and work area have not been checked. LightBurn has its own project and machine-file formats; its import list is broader than Studio's published list.

Check imported dimensions with a sample file

The size-check SVG below is artwork only. Its square is 20 mm wide and its circle is 10 mm in diameter. Import it and inspect the dimensions on screen before assigning any processing settings. It contains no power, speed or machine-control commands.

Run a final preview

Confirm the selected device, work area, origin, layer output, operation, power, speed units and passes. Review the processing preview and frame the design using the model's normal procedure. A file that looks correct in a drawing program can still contain an unexpected second outline or an image at the wrong size.

Frequently asked questions

Does changing a PNG filename to .svg make it a vector?

No. File renaming does not trace an image. Use genuine vector artwork or a supported tracing tool, then inspect the resulting geometry.

Why is a DXF imported at the wrong size?

Check the source drawing units and the imported dimensions. Do not send it to the machine until the physical size is verified.
