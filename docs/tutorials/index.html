Frequently Asked Questions

Quick answers to common questions about TOOCAA tutorials and laser engraving.

Which TOOCAA machine do I need to follow these tutorials? ▾

This library covers both the TOOCAA L2 and the enclosed TOOCAA NOVA. Check the model name, laser module, and accessory requirements in the linked guide before following its settings or workflow.

Do I need prior laser experience to get started? ▾

No. Start with the "Getting Started" filter for setup, safety, software, focus, and a first test project. Always verify focus and run a small material test before starting a full job.

What software do I need? ▾

TOOCAA Studio and LightBurn are the two software paths covered here. Use the Software filter to find setup and workflow references, then follow the guide that matches your machine and operating system.

How do I find the right parameters for a new material? ▾

Start with the wood settings calculator for a test plan, or open the official TOOCAA material settings page. Treat every value as a starting point and verify it on a small sample of the actual material.

Are these tutorials free to use? ▾

Yes. The learning resources linked from this library are free to open. Product and accessory links lead to TOOCAA's store, where availability and pricing are shown separately.

I'm having issues — where can I get help? ▾

Check the Troubleshooting section for symptom-based checks. If the issue remains, visit the Help Center or contact support and include your machine model, material, software, and settings.
