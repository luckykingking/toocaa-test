Prepare a Project in TOOCAA Studio

Prepare artwork at its finished size, choose the correct machine, and check the planned job before sending it from TOOCAA Studio.

Match the workspace to the machine

Use a current supported software release and the correct device profile. Confirm the model and laser module before applying material guidance. Product features and connection methods can change; the official software page is the reference for current support.

Work through the job

Use the following sequence with the current instructions for the exact machine. Keep the first job small enough to inspect clearly and leave time to check the result before repeating it.

  • Open or import the artwork and check its dimensions.
  • Separate engraving and cutting operations.
  • Select the connected machine and appropriate processing mode.
  • Verify speed units, enabled layers, and placement.
  • Frame and test before running the final design.

Keep a production copy

Save a working source and an exported version associated with the sample. Keep personalization fields easy to review and name files clearly. When a project is reopened on a different computer or software release, verify its settings before sending it to the machine.

Save the setup for the next job

Keep the artwork version, stock details, software version, laser module, focus method, speed units, power, passes, and a photo of the finished test together. If any of those change, run a fresh check rather than assuming the old result still applies.
