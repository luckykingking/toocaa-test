TOOCAA First Setup Checklist

Prepare a stable workspace, check the machine manual, arrange extraction, and run a small first job before starting a project.

Workspace before assembly

Set the machine on a stable, level surface with the clearances specified in its manual. Plan where smoke will be extracted and keep cables and the exhaust route clear of moving parts. The machine, laser module, and accessories should be identified before following assembly instructions.

Work through the job

Use the following sequence with the current instructions for the exact machine. Keep the first job small enough to inspect clearly and leave time to check the result before repeating it.

  1. Read the manual for the exact model and module.
  2. Check the delivered parts against the packing list and inspect for damage.
  3. Complete the documented assembly and ventilation setup with power disconnected.
  4. Install the supported software, then verify the connection and work area.
  5. Load a simple test file, frame it, and run it on a documented material.

Before the first full project

Check focus, workholding, framing, and the job's speed units. Stay at the machine while it runs. If motion, smoke extraction, or any safeguard does not work as documented, stop and resolve that issue before continuing.

Save the setup for the next job

Keep the artwork version, stock details, software version, laser module, focus method, speed units, power, passes, and a photo of the finished test together. If any of those change, run a fresh check rather than assuming the old result still applies.
